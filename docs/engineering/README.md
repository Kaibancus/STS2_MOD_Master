# 工程日志与看板

这是后续工程实施的统一入口，所有记录随代码版本管理。

| 入口 | 用途 |
| --- | --- |
| [实施计划](../implementation-plan.md) | 阶段、前置条件、验收门和范围变更 |
| [任务清单看板](tasks.md) | 谁在做什么、被什么阻塞、完成证据在哪里 |
| [BUG/FIX 看板](bugs.md) | 已确认问题、修复过程、复验和重新打开 |
| [工程日志](log.md) | 每批实际工作、结果、偏差和交接的追加记录 |
| [技术评估](../technical-assessment.md) | 风险清单和未证实假设，不混入缺陷统计 |

实施闭环：领取任务并更新状态 → 实现和必要验证 → 登记真实问题或偏差 →
追加日志 → 更新任务/缺陷状态及证据。

任务 ID、BUG ID 和 PRD 需求 ID 不随标题调整而复用或改号。
缺陷关闭需要复验，任务关闭需要验收证据；“已写代码”不等于“已完成”。
没有实际执行的步骤应明确写未执行，不能用空表、示例行或计划制造完成记录。
