## 拆分和关闭规则

内容规模明确后，C-05 拆为具体设计条目的子任务，保留父任务关系和 FR 引用；
禁止把一整套未明确设计的卡牌标记为“已完成”。

每项任务应在开始时补充负责人、具体输出与验收方式，结束时补充实现提交、
证据位置、未覆盖范围和关联 BUG ID。当前提交尚未产生时写“未提交”，
不得猜测提交哈希，也不要求当前提交在自身内容中引用自身哈希。

联机和创意工坊没有混入上述首期任务；后续立项时另行建立任务与验收矩阵。
